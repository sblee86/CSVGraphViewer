# CFCS_105 — 4개 표적 혼합 레이더 추적 테스트 데이터

실제 관측이 아닌, 난수 시드 105로 생성한 합성 테스트 데이터입니다.

- 4,800개 데이터 행, 36개 열, UTF-8 BOM, 첫 행은 열 이름
- Time_s: 0.0~119.9초, 0.1초 간격(10Hz)
- Target_ID: 1001, 1002, 1003, 1004. 표적별 1,200행
- Scan_ID 한 개마다 4개 표적을 한 번씩 보고하며, 그 안의 표적 순서는 무작위입니다.
- UTC 기준 시각: 2026-10-28 00:00:00.000부터. 프로그램의 시간축은 문자열 Timestamp_UTC 대신 숫자 Time_s를 사용하세요.

## CSVGraphViewer에서 보기

1. 압축을 풀고 CFCS_105.csv를 로컬 작업폴더에 넣습니다.
2. 데이터 탭에서 목록 새로고침을 누르고 해당 CSV를 엽니다.
3. 2D는 X축=Time_s, Y신호=Range_m / Speed_mps / SNR_dB 등을 선택합니다. 표적별 비교는 아래의 조건별 Y신호 기능을 사용하세요.
4. 한 표적만 보려면 스케일·값 범위의 조건 추가에서 Target_ID의 최소·최대를 똑같이 지정합니다. 예: 최소 1001, 최대 1001.
5. 3D는 반드시 표적번호 조건을 먼저 적용하고 X=X_m, Y=Y_m, Z=Z_m, T=Time_s를 선택하세요.
6. 현재 T까지 궤적을 선택하면 슬라이더/재생으로 관측 진행을 볼 수 있습니다.
7. CSV 미리보기 또는 별도 창에서 Target_ID 필터를 체크하면 표적별 표를 볼 수 있습니다. 표의 체크 필터는 그래프를 필터링하지 않으므로 그래프에는 4번 조건을 사용해야 합니다.

**한 파일의 여러 Target_ID를 자동으로 서로 다른 궤적으로 나누는 기능은 현재 없습니다.** 표적번호 조건 없이 3D로 그리면 서로 다른 표적의 점이 연결됩니다. 각 표적의 모양을 보려면 조건을 바꾸거나 표적별 양식으로 저장하세요.

## 표적별 움직임

| Target_ID | 시나리오 |
|---|---|
| 1001 | 접근하는 직선 궤적, 완만한 상승 |
| 1002 | 횡단하면서 좌우·고도가 조금씩 변하는 궤적 |
| 1003 | 멀어지면서 상승하는 직선 궤적 |
| 1004 | 낮은 속도로 선회하며 하강하는 궤적 |

## 열 설명

| 열 | 의미 |
|---|---|
| Time_s | 시작 후 경과 시간(초). X 또는 T에 권장 |
| Target_ID | 표적 식별 번호. 표적 분리용 조건 열 |
| X_m, Y_m, Z_m | 추적 위치(m). X=동쪽, Y=북쪽, Z=위쪽(ENU), 레이더 원점=(0,0,0) |
| Range_m | 측정 사거리(m). 미탐지 때는 빈 값 |
| Azimuth_deg | 측정 방위각(도). 북쪽 0°, 동쪽 90°, 시계방향 증가 |
| Elevation_deg | 측정 고각(도). 수평면 위가 양수 |
| Vx_mps, Vy_mps, Vz_mps | 추적 위치를 갱신하는 알파-베타 추적기의 속도 추정(m/s) |
| Speed_mps | 추적 속도 벡터의 크기(m/s) |
| RadialVelocity_mps | 거리 방향 속도(m/s), 멀어지면 양수/접근하면 음수. 미탐지 때 빈 값 |
| Doppler_Hz | 합성 도플러(Hz), 예시 파장 0.03m에서 -2×RadialVelocity/파장. 양수는 접근 |
| Acceleration_mps2 | 시나리오 기준 실제 가속도 크기(m/s²). 측정값이나 추적 추정값이 아닌 비교용 기준값 |
| Heading_deg | 추적 속도의 수평 진행 방향. 북쪽 0°, 동쪽 90° |
| ClimbRate_mps | 추적 상승률(m/s), Vz_mps와 동일. 음수는 하강 |
| SNR_dB | 거리에 따라 달라지는 합성 신호 대 잡음비(dB) |
| RCS_m2 | 표적별로 변동하는 합성 레이더 반사면적(m²) |
| Amplitude_dB | 표시 테스트용 합성 수신 레벨(dB), 실제 장비의 보정 레벨이 아님 |
| Track_Quality | 0~100 추적 품질 점수. 미탐지 중 감소 |
| Detection | 이번 관측 탐지 여부. 1=탐지, 0=미탐지 |
| Track_State | TENTATIVE=초기, CONFIRMED=확정, COASTING=미탐지 예측 유지 |
| Scan_ID | 관측 회차. 한 회차에 4개 표적 보고 |
| Timestamp_UTC | 관측 시각 문자열(UTC). 현재 프로그램 T에는 Time_s를 사용 |
| RangeSigma_m | 합성 거리 측정 잡음의 표준편차(8m) |
| AngleSigma_deg | 합성 방위각/고각 잡음의 표준편차(0.04°) |
| Measured_X_m, Measured_Y_m, Measured_Z_m | 잡음을 넣은 거리/방위각/고각을 ENU로 변환한 관측 위치(m). 미탐지 때 빈 값 |
| True_X_m, True_Y_m, True_Z_m | 잡음 없는 시나리오 기준 위치(m). 추적값과 비교용 |
| Measurement_Age_s | 마지막 탐지 후 지난 시간(초) |
| Hit_Count, Miss_Count | 표적별 누적 탐지/미탐지 횟수 |

X/Y/Z는 측정 위치에 알파-베타 갱신(α=0.35, β=0.03)을 적용한 추적 위치입니다. 미탐지 중에는 이전 속도로 예측하므로 위치는 이어지지만 관측 관련 값은 빈 셀입니다. 최초 속도는 시나리오 기준 속도로 초기화합니다.

1004는 40.0~41.9초, 1002는 85.0~85.4초에 미탐지입니다. 빈 값을 0으로 처리하지 않는지, Range/SNR 곡선의 끊김과 추적 위치의 예측 유지가 구분되는지 테스트할 수 있습니다.

## 네 표적 Range를 동시에 비교하기 (새 인터페이스)

- 함께 제공한 CFCS_105_4targets.json을 양식 가져오기로 읽고 해당 양식을 클릭하면, CFCS_105.csv를 찾아 Time_s / Range_m을 4개 표적으로 나누어 그립니다. 최신 CSVGraphViewer 버전이 필요합니다.
- 직접 만들려면 축 설정에서 Range_m 옆 조건을 누르고 Target_ID=1001로 적용합니다. 복제하여 값만 1002/1003/1004로 바꾸어 적용하세요. 신호별 개별 보기로 나누거나 겹칠 수 있습니다.
- 조건 추가로 한 신호에 Detection=1 같은 조건을 더 붙일 수 있습니다(AND). 값 선택 목록과 숫자·문자 비교를 지원합니다.
- 여러 표적을 비교할 때 파일 공통 조건에 Target_ID=1001을 남겨 두면 다른 표적이 제외됩니다. 공통 Target_ID 조건은 지우고 신호별 카드에서 설정하세요. 3D에서 한 표적 궤적을 보는 경우에는 기존의 공통 표적번호 조건을 사용합니다.
