Atelier CSVtoGraphViewer · 오프라인 버전

1. 실행
압축을 모두 푼 뒤 CSVtoGraphViewer.html을 Chrome으로 여세요.
HTML 한 파일에 화면, 코드, 스타일이 모두 들어 있습니다.
설치, 서버, 인터넷 연결, 외부 라이브러리 다운로드가 필요 없습니다.
source 폴더는 수정용 원본이며 실행 시 없어도 됩니다.

2. CSV 불러오기 / 내보내기
첫 행은 열 제목입니다. CSV 불러오기에서 파일을 선택하세요.
UTF-8이 기본이며 한글이 깨지면 CP949 / EUC-KR로 바꾸세요.
쉼표, 세미콜론, 탭을 자동 감지하거나 직접 선택할 수 있습니다.
따옴표 안 구분자와 줄바꿈, 연속 따옴표를 지원합니다.
행별 열 수가 다르거나 닫히지 않은 따옴표가 있으면 오류를 알립니다.
빈 숫자 셀은 0이 아닌 결측값이며 그래프 선을 끊습니다.
필터 CSV 저장은 조건을 통과한 행의 모든 열을 UTF-8 BOM으로 저장합니다.
원래 셀 문자열을 보존하며 그래프 확대 범위와 T 재생 구간은 CSV 필터에 포함되지 않습니다.
저장 파일 위치는 Chrome의 다운로드 설정을 따릅니다.

3. 2D 그래프
데이터 탭에서 X축과 Y축 신호를 선택합니다.
단일 / 복수 선택, 겹치기 / 신호별 개별 보기, 선 / 점 / 선+점을 지원합니다.
휠: 확대 / 축소
왼쪽 드래그: 영역 확대 (이동 모드에서는 위치 이동)
가운데 버튼을 누른 채 드래그: 항상 가로·세로 위치 이동
더블클릭 또는 전체 보기: 원래 범위 복원
오른쪽 조건은 최소·최대를 포함하며 여러 조건은 AND로 적용합니다.

4. 3D와 T
그래프 차원을 3D 궤적 그래프로 선택하세요.
X축은 왼쪽 데이터 탭, Y축과 Z축은 위쪽 메뉴에서 지정합니다.
3D는 한 CSV의 X·Y·Z 좌표를 이어 그리는 궤적 그래프입니다.
왼쪽 드래그: 회전 / 가운데 버튼 드래그: 이동 / 휠: 확대·축소
3D 각 축은 데이터 범위로 정규화해 표시합니다. 물리적 동일 축척은 아닙니다.
오른쪽 직접 축 범위 지정은 2D용입니다. 3D는 자동 데이터 범위를 사용합니다.
T는 숫자 시간 열 또는 행 순서를 선택합니다. 날짜 문자열은 직접 해석하지 않습니다.
T열을 선택하면 T 오름차순으로 궤적을 연결합니다. 같은 T는 원래 행 순서를 유지합니다.
현재 T까지 궤적: 슬라이더의 시간까지 표시합니다. 재생으로 진행할 수 있습니다.
재생은 고정 프레임 간격의 행 진행이며 실제 시간 간격을 그대로 재현하는 재생은 아닙니다.
2D에서도 T 슬라이더로 표시 구간을 제한할 수 있습니다.

5. 양식 저장 / 불러오기
왼쪽 양식 탭에서 양식명을 입력하고 양식 저장 (.json)을 누르세요.
X·Y·Z·T, 선택 신호, 2D/3D, 배치, 선/점, 조건, 2D 축 범위,
3D 시점과 확대·이동, T 표시 상태를 저장합니다. CSV 데이터는 포함하지 않습니다.
양식 파일 열기: JSON을 하나 또는 여러 개 읽습니다.
폴더 열기: 선택한 폴더의 하위 폴더까지 JSON을 찾아 목록에 표시합니다.
목록에서 양식 이름을 클릭하면 적용됩니다. 검색란에서 이름을 찾을 수 있습니다.
CSV를 먼저 열어도 되고, 양식을 먼저 선택한 뒤 CSV를 열어도 됩니다.
다른 CSV에도 열 제목으로 연결합니다. 같은 제목이 중복되면 같은 순번의 열을 사용합니다.
없는 열은 적용에서 제외하고 알려줍니다. 정확한 재현에는 같은 열 제목을 사용하세요.
브라우저를 닫으면 목록은 초기화됩니다. 다음 실행 때 양식 폴더를 다시 여세요.
양식 저장은 다운로드 방식입니다. 양식 폴더에 넣어 관리하면 편리합니다.

검증 범위
CSV 파싱/직렬화 왕복, 한글, BOM, 빈 셀, 0, 지수 표기, 인용부호,
셀 내부 줄바꿈, 구분자 감지, 오류 검출 테스트를 통과했습니다.
브라우저 파일 선택으로 CSV/양식 불러오기, CSV 다운로드 데이터 일치,
3D 표시, T 재생, 양식 적용을 확인했습니다.
단일 HTML과 동일한 내용을 HTTP 미리보기에서 브라우저 검증했습니다.
검증 환경에서 file:// 탐색은 허용되지 않아 직접 파일 열기 방식은 별도로 실행 검증하지 못했습니다.
대용량 데이터의 처리량은 PC 메모리와 Chrome 성능에 영향을 받습니다.

설정 메뉴: 화면 글자 8~40px(직접 입력), 그래프 축 글자 8~40px, 테마, 선 두께, 점 크기, 격자, 여백. 저장 및 닫기로 다음 실행에도 유지합니다. 취소/Escape는 변경 전으로 복원합니다. 브라우저 저장소를 지우거나 파일 위치를 변경하면 설정이 초기화될 수 있습니다.

수정판: 화면 글자 크기 덮어쓰기 오류 수정. 설정에서 아이콘 12~64px, 목록·표 줄 높이 20~80px 조절 가능. 설정 창은 조절 중에도 안정적으로 사용할 수 있도록 고정 글자 크기를 사용합니다.

작업폴더 방식
1. 시작 화면에서 작업폴더를 선택하고 Chrome의 읽기/쓰기 권한을 허용합니다.
2. 왼쪽 데이터 탭에서 폴더의 CSV/TSV를 검색하여 클릭합니다. 하위 폴더도 검색합니다.
3. 양식 탭의 저장 버튼은 작업폴더/양식/이름.json에 저장합니다. 다음 실행에 양식 목록을 자동으로 읽습니다. 양식 파일 열기로 가져온 양식도 이 폴더에 복사합니다.
4. 화면 설정은 작업폴더/CSVtoGraphViewer.settings.json에 저장합니다. 새 작업폴더는 기본 설정으로 시작합니다.
5. CSV/PNG 내보내기는 작업폴더/내보내기/에 저장합니다. 원본 CSV는 수정하지 않습니다. 같은 이름 저장 시 덮어쓰기 확인이 나옵니다.
6. 다음 실행 시 이전 폴더 권한이 유지되면 자동 연결합니다. 권한이 없으면 이전 작업폴더 연결 버튼을 누르세요. 브라우저 데이터 삭제/HTML 위치 변경 시 다시 선택해야 할 수 있습니다.
7. 상단에서 작업폴더를 변경하거나 목록을 새로고침할 수 있습니다. 외부 파일 변경은 새로고침으로 반영합니다. 브라우저 정책상 전체 절대 경로 대신 폴더명과 상대 경로를 표시합니다.
8. 데스크톱 Chrome/Edge의 File System Access 기능이 필요합니다.

세 탭 작업화면
- 상단의 작업폴더 표시줄과 파일/데이터분석/시각화 메뉴, 도구 리본은 제거했습니다.
- 데이터: 작업폴더 선택/변경, 목록 새로고침, CSV 불러오기, 문자 인코딩, 구분자, 폴더 CSV 목록과 현재 파일 정보를 표시합니다.
- 양식: 이름 입력, 작업폴더 양식 저장, 외부 양식 가져오기, 양식 검색/목록 선택을 제공합니다.
- 그래프설정: 배치, 선/산점도, 2D/3D, X/Y/Z/T 축과 Y신호, 시간 표시, 조건 필터, 축 범위와 통계를 제공합니다.
- 설정 버튼은 우측 상단입니다. 바깥 여백과 글자/아이콘/줄 높이는 계속 작업폴더 설정에 저장합니다.
- 전체 보기와 PNG/CSV 저장은 그래프 상단에 있습니다.
- 왼쪽 탭은 좌우 방향키로 이동할 수 있으며, 탐색기 오른쪽 경계를 끌어 폭을 조절합니다.
- 이전 설정 파일의 상단 도구 높이는 더 이상 사용하지 않습니다.

그래프설정 하위 탭과 우클릭 메뉴
- 그래프 종류: 2D/3D, 그래프 배치, 선/산점도, 시간 표시 방식
- 축 설정: X/Y/Z/T 열, 단일/복수 Y 신호와 검색
- 스케일·값 범위: 조건 범위 필터, 2D X/Y 표시 범위, 통계 (3D 축 범위는 기존 자동 범위 방식 유지)
- 그래프 위에서 마우스 오른쪽 버튼을 눌러 원하는 설정으로 바로 이동합니다.
- 우클릭 메뉴는 바깥 클릭 또는 Escape로 닫습니다. 키보드 Shift+F10으로도 열 수 있습니다.
- 왼쪽 위 로고를 그래프 분석 아이콘으로 변경하고 ATELIER 브랜드 표기를 제거했습니다.

여러 CSV 비교
- 데이터 탭에서 CSV 여러 개 추가를 누르고 Ctrl/Shift로 복수 선택합니다. 열린 파일은 목록에 추가됩니다. 작업폴더 파일은 체크한 뒤 선택 CSV 함께 열기로 동시에 읽습니다.
- 파일명을 누르면 현재 열린 파일에 추가합니다. 같은 상대 경로의 파일은 새 데이터로 갱신합니다. 하위 폴더의 같은 파일명은 상대 경로로 구분합니다.
- 불러온 CSV 목록의 ×는 원본 삭제가 아니라 화면에서 파일 제외입니다. 모두 닫기는 현재 데이터와 적용 대기 양식을 해제합니다.
- 그래프설정 > 축 설정에서 파일 경로별로 묶인 Y열을 선택합니다. 복수 선택으로 여러 파일 신호를 같은 2D 그래프에 그립니다. 그래프 종류 > 신호별 개별 그래프로 신호마다 나눠 봅니다.
- 각 CSV 신호는 해당 파일의 X열을 사용합니다. 공통 X열을 고르면 같은 이름의 X열을 파일별로 연결하며, 같은 열이 없는 파일은 첫 숫자 열을 사용하고 경고합니다. 파일별 X축 목록에서 각각 다시 선택할 수 있습니다. 행 수와 시간 간격이 달라도 CSV끼리 행을 합치거나 보간하지 않습니다.
- 조건 필터는 그 열이 속한 CSV에만 적용합니다. 여러 CSV 내보내기는 파일/열 이름을 붙인 열을 가진 하나의 CSV이며 다른 파일의 셀은 빈 값입니다. 파일 간 자동 병합/시간 동기화는 하지 않습니다.
- 양식에는 선택 신호의 상대 파일 경로, 열 이름, 중복 열 순번, 파일별 X열을 저장합니다. 해당 파일들을 함께 열면 다시 연결합니다. 없는 파일/열은 화면에 간단한 경고를 표시하고 사용 가능한 신호만 적용합니다.
- 외부 파일 선택창은 전체 폴더 경로를 제공하지 않으므로 파일명을 식별자로 사용합니다. 동일 이름의 다른 CSV는 작업폴더 하위 폴더에서 읽어 경로로 구분하세요.
- 3D의 X/Y/Z는 같은 CSV의 열을 선택합니다. 여러 파일 신호 비교는 2D 겹치기/개별 그래프에서 지원합니다.
- 스케일·값 범위의 축 범위 적용 바로 아래에 축 값 초기화가 있습니다. X/Y 수동 범위와 확대 범위를 지우고 자동 범위로 돌아갑니다. 조건 필터는 유지합니다.
- 설정에 그래프설정 메뉴 글자 크기(8~40px)를 추가했습니다. 전체 UI와 그래프 축 글자 크기와 독립적으로 적용하고 작업폴더에 저장합니다.

그래프 선택과 데이터 미리보기 연결
- 그래프의 실제 데이터 점 근처를 왼쪽 클릭하면, 해당 파일의 데이터 행과 선택 필드를 미리보기에 표시합니다. 겹친 신호는 화면에서 가장 가까운 점을 선택합니다.
- 선택한 셀의 값만 굵게 표시합니다. 파일명/데이터 행 번호/필드명도 미리보기 위에 표시합니다.
- 미리보기는 조건 적용 전 원본 파일 전체 데이터를 100행씩 표시합니다. 100행 이후의 점도 해당 페이지로 연결합니다. 파일 선택, 이전/다음, 데이터 행 직접 입력으로 전체를 탐색할 수 있습니다.
- 데이터 행 번호는 제목 행을 제외한 레코드 순번입니다. 셀 안 줄바꿈이 있는 CSV의 실제 텍스트 줄 번호와 다를 수 있습니다.
- 그래프 클릭 시 미리보기가 열리고 표 내부의 해당 셀이 보이도록 조절하지만, 화면 전체를 미리보기 위치로 스크롤하거나 포커스를 옮기지는 않습니다.
- 확대/이동/3D 회전 드래그, 가운데 버튼, 우클릭은 데이터 행 선택으로 처리하지 않습니다. 3D 점 선택은 해당 X/Y/Z 셀 값을 강조합니다.

양식으로 CSV 자동 열기
- 축 목록은 작업폴더명 없이 하위폴더/파일명/열 이름으로 표시합니다.
- 양식 저장 시 열린 CSV의 작업폴더 기준 상대 경로, 선택한 열 이름, 중복 열 순번과 파일별 X축을 기억합니다. CSV 데이터 자체는 저장하지 않습니다.
- 작업폴더 연결 후 양식 이름을 클릭하면 필요한 CSV를 자동으로 읽고 그래프를 표시합니다. 다른 작업폴더에도 같은 상대 경로의 파일이 있으면 사용할 수 있습니다.
- 상대 경로가 없으면 현재 작업폴더 전체에서 같은 파일명을 찾습니다. 같은 파일명이 여러 개이면 임의로 고르지 않고 경로 확인 메시지를 표시합니다.
- 파일이 없거나 읽을 수 없으면 기존 그래프를 유지합니다. 열이 없으면 누락 항목을 표시합니다.
- 예전의 열 이름만 저장된 양식은 기존처럼 먼저 연 CSV에 적용합니다. 파일 자동 열기를 사용하려면 CSV를 연 상태에서 양식을 다시 저장하세요.

개발 시 단일 HTML 갱신
- source/ 수정 후 python scripts/build_standalone.py로 CSVtoGraphViewer.html을 갱신합니다.
- 브라우저 회귀 검증: Python playwright와 Chromium이 있는 환경에서 python tests/browser_template_smoke.py.

양식 선택 삭제
- 양식 목록 왼쪽 체크박스로 삭제할 양식을 고른 뒤 목록 위의 선택 삭제 버튼을 누릅니다.
- 확인 후 작업폴더/양식/ 아래의 선택한 JSON 파일만 삭제합니다. 하위폴더 양식도 지원합니다.
- 검색으로 숨겨진 선택도 선택 개수에 포함되며 함께 삭제합니다. 확인창에 전체 경로가 표시됩니다.
- CSV 원본과 현재 표시 중인 그래프는 유지합니다. 삭제 실패한 양식은 선택을 유지하고 오류를 알립니다.

선택 데이터 강조와 표 스크롤
- 그래프에서 점을 선택하면 미리보기 표 내부 스크롤만 가로·세로로 이동하여 선택 값을 가운데에 표시합니다. 페이지 가장자리에서는 가능한 범위까지 이동합니다.
- 선택 값은 빨간색, 굵게, 기본 표 글자보다 한 단계 크게 표시합니다. 화면 전체와 그래프 영역은 이동하지 않습니다.

메인 요약·조작줄
- 전체 행, 조건 통과 행, 선택 신호, 보기 범위와 영역 확대/이동/축 범위 자동 버튼을 한 줄에 표시합니다.
- 설정의 그래프 요약·조작줄 크기(50~150%)로 이 줄의 글자, 버튼, 여백을 함께 조절합니다. 저장 및 닫기로 작업폴더에 저장하며 취소하면 이전 크기로 복원합니다.
- 축 범위 자동은 수동 X/Y 범위와 확대·이동을 초기화합니다. 3D는 확대·이동을 복원하고 회전 시점은 유지합니다. 조건 필터는 유지합니다.
- 화면이 좁으면 이 줄 안에서 가로 스크롤하여 모든 항목을 사용할 수 있습니다.

미리보기 열 필터와 정렬
- 첫 행의 열 이름 옆 ▼를 누르면 해당 파일 전체에서 찾은 고유 값과 각 값의 개수를 표시합니다. 현재 100행 페이지에만 한정하지 않습니다.
- 값 검색과 체크박스로 표시할 값을 선택한 뒤 적용합니다. 검색 값 전체 선택/해제는 현재 검색에 맞는 값에만 적용합니다. 빈 값은 (빈 셀)로 표시합니다.
- 여러 열의 필터는 AND로 적용합니다. 값이 많으면 값 더 보기로 추가 표시합니다.
- 오름차순/내림차순은 숫자를 숫자 크기로, 문자는 자연스러운 이름 순서로 정렬합니다. 빈 셀은 맨 뒤에 표시합니다. 정렬 해제는 원본 행 순서로 돌아갑니다.
- 이 열 필터 해제 또는 표 필터·정렬 초기화로 복원합니다. 취소/Escape/바깥 클릭은 체크 변경을 적용하지 않습니다.
- 미리보기 표에만 적용하며 CSV 원본, 그래프의 조건 필터 및 CSV 내보내기는 변경하지 않습니다. 데이터 행 번호는 원본 레코드 번호를 유지합니다.
- 그래프에서 선택한 점이 표 필터로 숨겨져 있으면 해당 행을 제외한 열 필터를 안내와 함께 해제하고 정렬 상태에 맞는 페이지에서 강조합니다.

선택 행과 빠른 축 조작
- 그래프에서 선택한 셀은 빨간색을 유지하며, 같은 데이터 행 전체를 굵게·기본 표 글자보다 1pt 크게 표시합니다. 행 번호도 함께 강조합니다.
- 메인 오른쪽 버튼 순서는 축 범위 자동 / 사용자 축 설정 적용 / 확대 / 이동입니다. 각 버튼은 글자와 여백의 기본 폭보다 1.2배 넓게 표시합니다.
- 축 범위 자동은 현재 표시 범위를 자동으로 돌리되, 사용자가 입력한 X/Y 최소·최대는 지우지 않습니다. 사용자 축 설정 적용으로 입력한 범위를 다시 적용합니다. 사용자 축 범위 적용은 기존처럼 2D에서 지원합니다.
- 메인 왼쪽 요약은 이름: 값 형식입니다. 요약·조작줄 크기 옵션은 그대로 적용됩니다.

양식 해제와 파일 작업 버튼
- 양식 가져오기, 양식 목록 새로고침, 작업폴더 변경, 목록 새로고침은 테두리와 배경이 있는 버튼으로 표시합니다.
- 양식 해제는 현재/적용 대기 양식을 취소하고 그래프를 기본 2D 설정으로 초기화합니다. 조건·수동 범위·시간 재생·미리보기 표 필터/정렬도 초기화합니다.
- 열어 둔 CSV, 작업폴더, 저장된 양식 파일과 화면 크기 설정은 유지합니다. 양식 해제는 저장된 JSON 삭제와 다릅니다.
- 예제 데이터 버튼과 생성 코드를 제거했습니다. 배포 패키지에 예제 CSV/양식은 포함하지 않습니다. 사용자의 기존 작업폴더 파일은 삭제하지 않습니다.
